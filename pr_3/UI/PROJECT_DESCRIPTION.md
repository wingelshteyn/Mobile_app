# AstRoll Messenger - Мобильное веб-приложение

## 📱 Описание проекта

**AstRoll Messenger** — это мобильное веб-приложение в стиле мистического фэнтези с использованием glassmorphism дизайна. Приложение представляет собой полнофункциональный мессенджер с дополнительными возможностями для работы с заметками, погодой и картами.

### 🎨 Визуальный стиль

Приложение выполнено в уникальном стиле **AstRoll**:
- **Тёмный фэнтези дизайн** с мистической атмосферой
- **Glassmorphism эффекты**: полупрозрачные карточки с blur, тонкими светлыми рамками и внутренними бликами
- **Атмосферный фон** с radial glow пятнами (синий, фиолетовый, зелёный) и звёздной пылью
- **Холодная цветовая палитра**: серебристые тона, голубые акценты, приглушённый красный для опасных действий
- **Плавные анимации** и hover-эффекты для улучшения UX

## 🎨 Дизайн-система AstRoll

### Цветовая палитра

\`\`\`css
/* Фоновые слои */
--bg: rgba(12, 13, 17, 0.42)
--paper: rgba(22, 23, 29, 0.92)

/* Текст */
--text: #e8e9f0
--text-muted: #9a9eac
--text-accent-strong: #d8dce6

/* Акценты */
--blue-accent: #7ec8f0
--danger-accent: #b84a52

/* UI элементы */
--line: rgba(255, 255, 255, 0.10)
--elevated: rgba(255, 255, 255, 0.032)
--input-surface: rgba(0, 0, 0, 0.36)
\`\`\`

### Glassmorphism эффект

**Стеклянная карточка:**
- \`backdrop-filter: blur(18px)\`
- \`border: 1px solid rgba(255,255,255,0.12)\`
- \`background\`: градиент от светлого к тёмному
- \`box-shadow\`: глубокая тень + внутренний блик

**Визуальные принципы:**
- Не использовать яркий neon cyberpunk
- Сохранять читаемость текста
- Мягкие анимации (150-260ms)
- Тонкие рамки и деликатные glow эффекты

## 📱 Mobile-First подход

- **Основной таргет**: мобильные устройства (320px - 480px)

- **Touch-friendly**: все кнопки и интерактивные элементы >= 44px

5. **Topbar** — верхняя панель с действиями
6. **BottomNav** — нижняя навигация

**Преимущества:**
