# Руководство пользователя — Astroll (краткая версия для pr_5)

Полная версия: `../pr_4/USER_GUIDE.md`.

## Запуск

1. Установите APK ([BUILD_APK.md](BUILD_APK.md)) или запустите из Android Studio.
2. Android **7.0+**, нужен **интернет** (карта и погода).
3. Кнопка **☰** — меню разделов.

## Разделы

| Раздел | Описание |
|--------|----------|
| **Чаты** | Список диалогов (демо) |
| **Заметки** | Локальные заметки (Room) |
| **Погода** | Open-Meteo, Томск |
| **Карта** | OpenStreetMap, метки по Томску |
| **Настройки** | Версия и параметры (демо) |

## Карта

- Жесты двумя пальцами — масштаб и перемещение.
- Нажатие на метку — название и описание.

## Погода

- Кнопка **Обновить** — повторный запрос к API.
- Без сети — сообщение об ошибке.
