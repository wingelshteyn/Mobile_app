# План монетизации и публикации приложения Astroll

Приложение: **Astroll** (`ru.vladik.mobikiui`) — учебный мобильный клиент с чатами, заметками, картой (OSM) и погодой (Open-Meteo).

---

## 1. Целевая аудитория и позиционирование

| Параметр | Описание |
|----------|----------|
| **Аудитория** | Студенты, молодые пользователи 16–30 лет, интерес к локальным сервисам (карта, погода) |
| **Платформа** | Android 7.0+ (API 24), смартфоны и планшеты |
| **Конкуренты** | Telegram, заметки (Google Keep), погодные виджеты, 2GIS / Яндекс.Карты |
| **УТП** | Единое «лёгкое» приложение: чаты + заметки + карта + погода в одном тёмном UI (Astroll) |

Для **учебной** версии монетизация минимальна; ниже — план развития до коммерческой публикации.

---

## 2. План монетизации

### 2.1. Модель: Freemium + реклама (основная)

| Уровень | Бесплатно | Premium (подписка) |
|---------|-----------|---------------------|
| Чаты | Демо / до 5 чатов | Безлимит, синхронизация |
| Заметки | До 50 заметок | Безлимит, экспорт |
| Карта | OSM, 4 метки | Свои метки, маршруты |
| Погода | 1 город | Несколько городов, виджет |
| Реклама | Баннер внизу списка чатов | Без рекламы |

**Ориентировочная цена Premium:** 99–149 ₽/мес или 799 ₽/год (регион RU).

### 2.2. Дополнительные источники дохода

1. **Реклама (AdMob)** — ненавязчивые баннеры / rewarded video («обновить погоду без ожидания»).
2. **Разовые покупки (IAP)** — темы оформления Astroll (99 ₽), набор иконок чатов.
3. **Партнёрства** — реферальные ссылки на погодные/картографические сервисы (при масштабировании).
4. **B2B / white-label** — кастомизация UI для вузовских проектов (нишевая модель).

### 2.3. Этапы внедрения монетизации

| Этап | Срок | Действия |
|------|------|----------|
| **MVP (сейчас)** | 0 ₽ | Учебная сборка, без рекламы и платежей |
| **v1.0** | 1–2 мес. | Google Play, политика конфиденциальности, crashlytics |
| **v1.1** | +1 мес. | AdMob (только free-версия) |
| **v1.2** | +1 мес. | Google Play Billing — подписка Premium |

### 2.4. Юридические требования перед монетизацией

- Политика конфиденциальности (обработка данных погоды/карты — только запросы к API, без аккаунта).
- Пользовательское соглашение.
- Согласие на рекламу и аналитику (GDPR / 152-ФЗ при сборе данных).
- Регистрация ИП/самозанятого при приёме платежей в РФ.

## 3. План публикации в Google Play

### 3.1. Подготовка

1. **Аккаунт разработчика** — Google Play Console (единоразово ~$25).
2. **Подпись release** — keystore, `signingConfig` в `build.gradle.kts`, AAB вместо APK.
3. **Материалы магазина:**
   - Название: *Astroll — чаты, заметки, карта*
   - Краткое описание (80 символов)
   - Полное описание (4000 символов) — функции pr_3–pr_5
   - Иконка 512×512, feature graphic 1024×500, скриншоты 6–8 шт.
4. **Контент-рейтинг** — анкета IARC (обычно «Для всех» / 3+).
5. **Data safety** — указать: интернет, локальное хранение заметок, без передачи ПДн на свой сервер.

### 3.2. Технический чеклист релиза

- [ ] `versionCode` / `versionName` увеличены
- [ ] `targetSdk` актуален (35)
- [ ] Release AAB: `./gradlew bundleRelease`
- [ ] ProGuard/R8 включён для release (см. [SECURITY.md](SECURITY.md))
- [ ] Тест на 3+ устройствах, разные DPI
- [ ] Проверка карты и погоды при включённом интернете

### 3.3. Каналы публикации

| Канал | Назначение |
|-------|------------|
| **Google Play** | Основной магазин |
| **RuStore** | Альтернатива для РФ |
| **GitHub Releases** | APK для учёбы / тестировщиков |
| **Прямая раздача** | Сайт вуза + QR на debug/release APK |

### 3.4. Поддержка после публикации

- Ответы на отзывы в Play Console (48 ч).
- Обновления раз в 4–6 недель (исправления + мелкие фичи).
- Мониторинг ANR/crash через Firebase Crashlytics.

## 5. Риски и ограничения

| Риск | Митигация |
|------|-----------|
| Зависимость от OSM / Open-Meteo | Кэш, fallback-сообщения, альтернативный tile-сервер |
| Низкая монетизация учебного MVP | Сначала публикация как portfolio, монетизация во v1.1+ |
| Отклонение в Play (permissions) | Минимум разрешений (только INTERNET + NETWORK_STATE) |
