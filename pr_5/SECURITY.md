# Средства обеспечения безопасности приложения Astroll

Приложение: **Astroll** (`ru.vladik.mobikiui`), Kotlin, Jetpack Compose, minSdk 24, targetSdk 35.

---

## 1. Сетевая безопасность

| Мера | Реализация в проекте |
|------|----------------------|
| **Только HTTPS для API** | Погода: `https://api.open-meteo.com/` (Retrofit). Секретный API-ключ не требуется и не хранится в коде. |
| **Запрет незашифрованного HTTP** | В `AndroidManifest.xml`: `android:usesCleartextTraffic="false"` — приложение не принимает cleartext-трафик по умолчанию. |
| **Минимум сетевых разрешений** | Только `INTERNET` и `ACCESS_NETWORK_STATE` — нет доступа к SMS, контактам, геолокации GPS (координаты для погоды заданы константами для Томска). |
| **Карта** | WebView + Leaflet загружает тайлы OSM по **HTTPS** (`tile.openstreetmap.de`). |

**Риск:** загрузка скриптов Leaflet с CDN (`unpkg.com`) — требует интернет; для production рекомендуется встроить библиотеку в `assets/`.

---

## 2. Защита данных на устройстве

| Мера | Реализация |
|------|------------|
| **Локальные заметки** | База **Room** (`AppDatabase`) — данные хранятся в приватной директории приложения, недоступной другим приложениям без root. |
| **Нет облачной синхронизации** | В учебной версии заметки не отправляются на сервер — снижен риск утечки при перехвате. |
| **Резервное копирование** | `android:allowBackup="true"` — Android Backup может копировать данные приложения. Для production с чувствительными данными рекомендуется `allowBackup="false"` или исключение БД в `backup_rules.xml`. |

---

## 3. Безопасность компонентов Android

| Мера | Реализация |
|------|------------|
| **Один экспортируемый Activity** | Только `MainActivity` с `android:exported="true"` и intent-filter LAUNCHER. |
| **Нет лишних exported-компонентов** | Сервисы/приёмники не экспортируются посторонним приложениям. |
| **Application class** | `MobikiApplication` — инициализация БД, без хранения паролей в памяти. |

---

## 4. Безопасность кода и сборки

| Мера | Статус / рекомендация |
|------|------------------------|
| **Язык Kotlin** | Null-safety, меньше типичных ошибок памяти, чем в Java. |
| **Coroutines + ViewModel** | Сетевые запросы погоды в `Dispatchers.IO`, UI-state через `ViewModel` — нет блокировки UI-потока. |
| **ProGuard / R8** | В release сейчас `isMinifyEnabled = false`; файл `proguard-rules.pro` подготовлен. **Для публикации в Play** рекомендуется включить обфускацию и сжатие. |
| **Зависимости** | Версии из Maven Central / Google; регулярное обновление BOM Compose и AndroidX. |

---

## 5. Конфиденциальность и персональные данные

| Аспект | Поведение приложения |
|--------|----------------------|
| **Регистрация / логин** | Отсутствует |
| **Сбор ПДн** | Не ведётся (нет аналитики Firebase в учебной сборке) |
| **Геолокация пользователя** | Не запрашивается; погода — фиксированные координаты Томска |
| **Чаты** | Демо-статические данные (`StaticData`) |
| **Сторонние API** | Open-Meteo, OpenStreetMap — передаётся только запрос погоды по координатам / загрузка тайлов карты |

При коммерческой публикации необходима **политика конфиденциальности** с описанием этих запросов.

---

## 6. Подпись и дистрибуция

| Мера | Описание |
|------|----------|
| **Debug APK** | Подпись debug-keystore — только для разработки и учёбы |
| **Release** | Требуется собственный **keystore**, хранить пароли вне репозитория (не коммитить `*.jks`, `keystore.properties`) |
| **Google Play** | Рекомендуется **Play App Signing** — Google хранит ключ подписи дистрибуции |

---

## 7. Угрозы и меры (краткая матрица)

| Угроза | Вероятность | Мера |
|--------|-------------|------|
| Перехват HTTP | Низкая | HTTPS-only |
| Утечка API-ключа | Нет ключа | Публичные API без секрета |
| Чтение заметок другим приложением | Низкая | Sandbox Android |
| Подмена APK | Средняя | Подпись release, публикация только через Play |
| XSS в WebView карты | Низкая | Контент генерируется локально, без пользовательского HTML |

---

## 8. Рекомендации перед публикацией в магазин

1. Включить **R8/ProGuard** для release.
2. Добавить **network_security_config** при необходимости исключений.
3. Отключить или ограничить **allowBackup** для заметок.
4. Вынести Leaflet в **assets** (без CDN).
5. Подключить **Certificate Pinning** для критичных API (опционально).
6. Провести проверку зависимостей (`./gradlew dependencyCheck` / Dependabot).

---

## 9. Итог

В текущей учебной версии безопасность обеспечивается **минимизацией разрешений**, **HTTPS**, **локальным хранением данных**, **отсутствием учётных записей и секретов в коде**. Для промышленной публикации требуется подписанный release, обфускация и юридические документы (см. [MONETIZATION_AND_PUBLICATION_PLAN.md](MONETIZATION_AND_PUBLICATION_PLAN.md)).
