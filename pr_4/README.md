# Практическая работа 4 — карта и внешний API

Проект продолжает **pr_3** (приложение **Astroll** на Kotlin + Jetpack Compose). Исходный код: папка **`Android/`** (скопировано из `../pr_3/Android/` с функциями pr_4: карта + Open-Meteo).

## Выполненные пункты задания

| Пункт | Реализация |
|-------|------------|
| **1. Карта** | **OpenStreetMap** через библиотеку **osmdroid** (`MapScreen`, `OsmMapView`). Метки с названием и описанием (Томск, 4 точки). |
| **2. Внешний API** | **Open-Meteo** (`https://api.open-meteo.com`) — текущая погода для Томска, без API-ключа (`WeatherScreen`, `WeatherRepository`). |
| **3. UI** | Данные карты и погоды выводятся на вкладках **«Карта»** и **«Погода»** в боковом меню. |
| **4. Документация** | [Руководство пользователя](USER_GUIDE.md), [сборка APK](BUILD_APK.md). |

## Быстрый старт

1. Откройте `Android/` в Android Studio **или** соберите APK из командной строки (см. `BUILD_APK.md`).
2. На устройстве/эмуляторе нужен **интернет** (карта — тайлы OSM, погода — REST API).
3. Меню (☰) → **Карта** / **Погода**.

## Сдача

Заархивируйте папку **`pr_4`** (или минимум `pr_4/Android/` + `USER_GUIDE.md` + `BUILD_APK.md`) в формате, указанном преподавателем, либо загрузите в открытый репозиторий со ссылкой на инструкцию по сборке.
