# Руководство пользователя — Astroll (практическая работа 4)

Приложение **Astroll** — учебный мобильный клиент с вкладками в стиле мессенджера (оформление Astroll). В работе 4 добавлены **карта с метками** и **погода из интернета**.

---

## Запуск и навигация

1. Установите APK (см. `BUILD_APK.md`) или запустите из Android Studio на телефоне/эмуляторе с **Android 7.0+** (API 24).
2. Включите **Wi‑Fi или мобильный интернет** — без сети карта и погода работать не будут.
3. Откройте приложение. Вверху — заголовок текущего раздела, слева — кнопка **☰ (меню)**.
4. В боковом меню выберите раздел:
   - **Чаты** — список диалогов (демо-данные).
   - **Заметки** — заметки в локальной базе (практика 3): создание, редактирование, удаление.
   - **Погода** — данные с сайта **open-meteo.com**.
   - **Карта** — **OpenStreetMap** с метками по Томску.
   - **Настройки** — версия приложения и параметры (демо).

---

## Вкладка «Карта»

### Что отображается

- Интерактивная карта **OpenStreetMap** (подложка Mapnik).
- Под картой — список **меток** с текстовым описанием.

### Как пользоваться

| Действие | Результат |
|----------|-----------|
| Движение двумя пальцами | Сдвиг карты |
| Сведение/разведение пальцев | Уменьшение/увеличение масштаба |
| Нажатие на метку на карте | Всплывающее окно: **название** и **описание** точки |

### Метки (Томск)

1. **Площадь Ленина** — центр города.  
2. **Томский государственный университет** — главный корпус.  
3. **Набережная р. Томи** — прогулочная зона.  
4. **Ледовый дворец** — спортивный комплекс.

Карта при открытии центрируется на первой метке; все метки видны на карте одновременно.

## Вкладка «Погода»

### Источник данных

- Открытый API **Open-Meteo**: `https://api.open-meteo.com/v1/forecast`
- Координаты: **Томск** (широта/долгота заданы в коде приложения).
- Регистрация и API-ключ **не требуются**.

### Что показывается на экране

- Город (подпись «Томск (Open-Meteo)»).
- Текстовое описание погоды (ясно, дождь, снег и т.д. по коду WMO).
- Температура и «ощущается как».
- Скорость ветра (м/с) и относительная влажность (%).

### Действия

- При открытии вкладки данные **загружаются автоматически** (кратко виден индикатор «Загрузка…»).
- Кнопка **«Обновить»** — повторный запрос к API.
- При ошибке сети — сообщение об ошибке и кнопка **«Повторить»**.

## Остальные разделы (кратко)

- **Заметки** — поля «Заголовок», «Текст», «Тег»; **«Сохранить заметку»**; в списке — редактировать / удалить.
- **Чаты** и **Настройки** — статические демо-данные из практики 2.

---

## Требования и ограничения

- Нужны разрешения **Интернет** и **состояние сети** (запрашиваются системой при установке, отдельного диалога в приложении нет).
- Карта загружает тайлы с серверов OpenStreetMap; при медленном интернете карта может подгружаться постепенно.
- Погода актуальна на момент последнего успешного запроса к API.

## Техническая справка (для отчёта)

| Компонент | Технология |
|-----------|------------|
| Карта | osmdroid + OpenStreetMap |
| Погода | Retrofit + Gson → Open-Meteo REST |
| UI | Jetpack Compose, Material 3 |
| Локальные заметки | Room (SQLite), практика 3 |

Файлы: `MapScreen.kt`, `OsmMapView.kt`, `WeatherScreen.kt`, `WeatherRepository.kt`, `MapMarker.kt` (объект `MapMarkers`).
